# ENSO-Forecasting using Machine Learning & Explainable AI
ENSO Event Forecasting using Machine Learning and Explainable AI (SHAP) with an interactive Streamlit dashboard for climate prediction and event detection.
## Overview
This project predicts ENSO (El Niño Southern Oscillation) events using climate variables and machine learning models.
## Features
- ONI Forecasting
- ENSO Event Detection
- Streamlit Dashboard
- SHAP Explainability
- Model Comparison
## Models Used
- Random Forest
- Linear Regression
- XGBoost
- SVR
## Best Model
Random Forest
RMSE: 0.2787
R² Score: 0.6493
## Tech Stack
Python, Pandas, NumPy, Scikit-Learn, SHAP, Streamlit
